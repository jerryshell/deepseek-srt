# DeepSeek SRT 上传助手

Tampermonkey 用户脚本：在 DeepSeek 上传 `.srt` 字幕并批量总结 MD/SRT 文件，在 YouTube 页面下载字幕。

推荐搭配 [陪读蛙](https://github.com/mengxi-ream/read-frog) 获取 YouTube 字幕，也可用脚本自带的「下载字幕」按钮。

## 功能

- **SRT 伪装**：拖入 `.srt` 时自动改名为 `.txt` 上传，通过 DeepSeek 的格式校验
- **自动填空**：拖入 `.srt` 或 `.md` 后填入提示词（默认「通俗易懂总结」，输入框已有内容时不覆盖）
- **发送后新对话**：发送完成后自动开启新会话（默认关闭）
- **批量处理**：一次选多个 `.md` / `.srt`，逐个上传、填空、发送，每个文件独立会话，最多 2 个并发，可随时停止；失败后清理残留，限流时 60 秒后重试（最多 5 次）
- **YouTube 字幕下载**：视频信息区右上角提供「下载字幕」「下载并关闭」，多轨道时可选择

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本，粘贴 [main.js](./main.js) 全部内容
3. 保存后打开 [DeepSeek](https://chat.deepseek.com/) 或 [YouTube](https://www.youtube.com/)

## 使用

- **单文件**：拖入 `.srt` 或 `.md`，脚本上传文件并填入提示词，手动发送
- **批量**：面板点「批量上传 MD/SRT」多选文件，确认任务列表后点「开始处理」；运行中按钮变为「停止处理」，面板显示进度条与逐项状态（等待、处理中、生成中、完成、失败、已停止）
- **面板**：右上角「SRT 助手」可收起或展开，内含开关、提示词编辑与批量入口；底部日志区可展开并一键复制

## 边界

- 批量接管条件为选中 2 个及以上且全部是 `.md` / `.srt`，混选其他类型时仍走 DeepSeek 原流程
- 批量完成信号取自侧边栏「新对话」会话数，站点改版后可能失效
- 「发送后新对话」在已有会话内发送时不触发
