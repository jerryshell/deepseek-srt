# DeepSeek SRT 上传助手

油猴脚本，让 DeepSeek 直接支持拖入 `.srt` 字幕文件（自动伪装为 `.txt`），并可选择拖入时自动填入提示词。

推荐使用 **[陪读蛙](https://github.com/mengxi-ream/read-frog)** 下载 YouTube 字幕，或使用脚本内置的 YouTube 字幕下载按钮（视频标题右侧）。

## 功能

- **自动伪装**: `.srt` 文件自动重命名为 `.txt`，绕过 DeepSeek 的前端格式校验
- **自动填空**: 可选拖入 `.srt` / `.md` 后自动在输入框填入预设提示词（默认: 通俗易懂总结，已有内容不覆盖）
- **发送后新对话**: 可选发送后自动开启新对话，适合批量处理字幕（默认关，找不到按钮时用 Ctrl+J 快捷键兑底）
- **批量处理 MD/SRT**: 面板“批量上传 MD/SRT”按钮（或 Ctrl+Shift+U）多选 `.md` / `.srt`（srt 自动伪装为 .txt），任务列表直接显示在面板中，逐项标记状态（等待/处理中/生成中/完成/失败），点“开始处理”后自动逐个上传、填空、发送，并发 2 自动排队，运行中按钮变“停止处理”可随时中止，完成后弹窗展示统计、失败明细和上传诊断日志（可一键复制）
- **YouTube 字幕下载**: 在 YouTube 视频标题右侧显示“下载字幕”和“下载并关闭”按钮，一键下载 `.srt` 字幕（支持多轨道选择，下载并关闭可自动关标签页）
- **页面控制面板**: 右上角“SRT 助手”面板集中控制全部功能（自动填空 SRT / MD 开关、发送后新对话、修改提示词、批量上传 MD），无需打开 Tampermonkey 菜单，所有提示也显示在面板内（不弹系统对话框）

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本，粘贴 [main.js](./main.js) 全部内容
3. 保存，打开 [DeepSeek 聊天页](https://chat.deepseek.com/) 或 [YouTube](https://www.youtube.com/) 即可使用

## 使用

- **拖入 .srt 文件**: 自动上传，无感知
- **批量处理**: 右上角“SRT 助手”面板点“批量上传 MD/SRT”（或 Ctrl+Shift+U），多选 `.md` / `.srt` 后任务列表显示在面板中（逐项状态标记），点“开始处理”全自动排队（srt 自动伪装为 .txt），并发 2，运行中可点“停止处理”中止，完成弹窗可复制统计、失败明细和诊断日志
- **点击 Tampermonkey 图标**: 无需，全部控制已移到页面右上角“SRT 助手”面板（开关实时生效，无需刷新）
