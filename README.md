# DeepSeek SRT 上传助手

油猴脚本：让 DeepSeek 支持上传 `.srt` 字幕，并批量总结 MD/SRT 文件。

推荐搭配 [陪读蛙](https://github.com/mengxi-ream/read-frog) 下载 YouTube 字幕，也可用脚本自带的 YouTube 下载按钮。

## 功能

- **SRT 自动伪装**: 拖入 `.srt` 文件自动改名为 `.txt` 上传，绕过格式校验
- **自动填空**: 拖入 `.srt` / `.md` 后自动填入提示词（默认「通俗易懂总结」，已有内容不覆盖）
- **发送后新对话**: 可选发送后自动开启新会话（默认关）
- **批量处理**: 面板选多个 `.md` / `.srt`（SRT 自动伪装为 `.txt`），自动逐个上传、填空、发送、总结，每个文件独立会话，并发 2 排队，可随时停止，失败自动清理不串会话，发送间隔可调（默认 3~5 秒随机，防风控）
- **YouTube 字幕下载**: 视频标题旁显示「下载字幕」「下载并关闭」按钮，支持多轨道选择

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本，粘贴 [main.js](./main.js) 全部内容
3. 保存，打开 [DeepSeek](https://chat.deepseek.com/) 或 [YouTube](https://www.youtube.com/) 使用

## 使用

- **单文件**: 直接拖入 `.srt` 或 `.md`，自动上传并填提示词
- **批量**: 右上角「SRT 助手」面板点「批量上传 MD/SRT」（或 Ctrl+Shift+U）多选文件 → 面板显示任务列表 → 点「开始处理」。运行中按钮变「停止处理」，面板显示进度条和逐项状态（等待/处理中/生成中/完成/失败/已停止），底部日志实时记录可一键复制
- **面板**: 右上角「SRT 助手」，标题栏可收起/展开；开关（自动填空 SRT/MD、发送后新对话）、提示词编辑（点文本直接改）、发送间隔（点 ✎ 改基准秒数，实际基准到基准+2 秒随机）、批量入口都在面板内
